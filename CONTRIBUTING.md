# Contributing to ATEN

Thank you for your interest in contributing to **ATEN (Autonomous Travel Execution Network)**.

ATEN demonstrates a **Companion AI Agent Architecture** built on top of **KeeperHub's execution layer**, showcasing how a Main Service AI Agent can dynamically associate with a Companion AI Agent Network to orchestrate multiple specialized workflows.

We welcome contributions that improve the project, documentation, architecture, developer experience, and integration with KeeperHub.

---

## Ways to Contribute

You can contribute by:

- Improving project documentation
- Enhancing architecture diagrams
- Expanding AI Agent workflows
- Improving KeeperHub integration
- Optimizing workflow orchestration
- Fixing bugs or improving code quality
- Adding tests and examples
- Suggesting new Companion AI Agents
- Improving onboarding for new developers

---

## Getting Started

1. Fork the repository.
2. Create a feature branch.

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes.

4. Commit your work.

```bash
git commit -m "Add meaningful description"
```

5. Push your branch.

```bash
git push origin feature/your-feature-name
```

6. Open a Pull Request.

---

## Contribution Guidelines

Please ensure that your contribution:

- Aligns with ATEN's architecture
- Preserves compatibility with KeeperHub
- Includes clear documentation where appropriate
- Follows clean and readable coding practices
- Does not introduce breaking changes without discussion

---

## Reporting Issues

If you discover a bug or have an enhancement proposal, please open a GitHub Issue describing:

- The problem
- Expected behaviour
- Actual behaviour
- Steps to reproduce (if applicable)

---

## Code Style

We encourage contributors to:

- Write clean and maintainable code
- Keep functions modular
- Add comments where necessary
- Follow consistent naming conventions
- Keep documentation synchronized with implementation

---

## Project Philosophy

ATEN is an architectural demonstration of how autonomous AI systems can leverage **KeeperHub's execution layer** to coordinate reliable multi-agent workflow execution.

Every contribution should support one or more of the following goals:

- Reliable workflow execution
- Multi-agent orchestration
- Reusable workflows
- Better developer experience
- Improved KeeperHub integration

---

## Code of Conduct

By participating in this project, you agree to be respectful, collaborative, and constructive.

We value open discussion, technical excellence, and contributions that help improve the project for the wider community.

---

Thank you for helping improve **ATEN**.

Together, we can advance the future of reliable autonomous AI execution on **KeeperHub**.
