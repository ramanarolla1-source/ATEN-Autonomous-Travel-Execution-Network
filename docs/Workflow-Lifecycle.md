# Workflow Lifecycle

## Overview

ATEN separates **AI reasoning** from **workflow execution**.

AI Agents are responsible for understanding user intent and writing workflows, while **KeeperHub** is responsible for validating, simulating, executing, auditing and preserving those workflows.

Every workflow within ATEN—whether generated by the Main Service AI Agent or a Companion AI Agent—follows the same execution lifecycle.

## Workflow Stages

### 1. Customer Intent

The traveller provides destination, travel dates, preferences, budget and other requirements.

These inputs define the customer's primary intent.

---

### 2. Main Service AI Agent

The Main Service AI Agent:

- Understands customer intent.
- Performs reasoning.
- Generates the primary workflow.

The workflow describes **what needs to be executed**, not how blockchain transactions are performed.

---

### 3. MCP Communication

The generated workflow is securely delegated to KeeperHub through the **Model Context Protocol (MCP)**.

MCP provides a standardized communication layer between AI Agents and KeeperHub.

---

### 4. KeeperHub Execution & Reliability Layer

KeeperHub manages the complete execution lifecycle.

#### Workflow Validation

Verifies that the workflow is complete and suitable for execution.

#### Simulation

Executes the workflow in a simulated environment before irreversible blockchain transactions occur.

#### Workflow Orchestration

Coordinates the execution sequence and prepares the workflow for deployment.

#### Reliable On-Chain Execution

Executes validated workflows with deterministic reliability.

#### Retry Logic

Automatically retries recoverable failures to improve execution reliability.

#### Audit Trail

Records every workflow execution to provide transparency and traceability.

#### Workflow Preservation

Preserves validated workflows for future reuse, reducing repeated LLM reasoning and improving execution consistency.

---

## Primary Workflow Completion

Unlike conventional AI applications, successful completion of the primary workflow does **not** conclude execution.

Instead, it automatically activates the **Companion AI Agent Network**.

---

## Companion Workflow Lifecycle

Each Companion AI Agent follows exactly the same execution lifecycle:

1. Perform specialized reasoning.
2. Write a specialized workflow.
3. Submit the workflow through MCP.
4. KeeperHub validates the workflow.
5. Simulation is performed.
6. Workflow is orchestrated.
7. Reliable on-chain execution occurs.
8. Execution is recorded through the Audit Trail.
9. Validated workflow is preserved for future reuse.

This consistent execution model enables multiple autonomous AI Agents to share the same execution and reliability layer.

---

## Workflow Philosophy

ATEN demonstrates a simple architectural principle:

> **AI Agents perform reasoning and write workflows. KeeperHub reliably executes those workflows.**

By extending this execution model from a single Main Service AI Agent to a coordinated Companion AI Agent Network, ATEN demonstrates how KeeperHub can orchestrate an ecosystem of specialized autonomous workflows generated from a single customer request.
